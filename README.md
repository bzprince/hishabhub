# HishabHub

A digital control center for small businesses. Products, orders, expenses and profit in one place.

> **Demo version.** This is an early demo built to show the idea and the interface. It is not a finished product, and the data in it is sample data only.

**Live demo:** https://hishabhub.netlify.app/

## What it does
- Keep track of **products**
- Manage **orders**
- Record **expenses**
- See **profit** at a glance

## Built with
HTML · CSS · JavaScript

## Status
Demo / work in progress. Features may be incomplete and can change.
