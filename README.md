# HishabHub

**A digital control center for small businesses.**

Manage products, orders, expenses, and profit from one place. HishabHub aims to make everyday business management simpler, smarter, and more organized.

> **Demo version.** HishabHub is currently an early-stage demo built to showcase the concept and user interface. Some features are incomplete, and the data is sample data only.

**Live Demo:** https://hishabhub.netlify.app/

---

## Features

- **Dashboard** – Get an overview of your business activities and financial summaries.
- **Product Management** – Add, edit, and manage products, prices, and stock.
- **Order Management** – Create and manage orders with different order statuses.
- **Expense Tracking** – Record business expenses and organize them by category.
- **Profit Overview** – View revenue, expenses, and estimated profit.
- **Demo Mode** – Explore the interface with sample business data.
- **Responsive Design** – Use the interface on desktop and mobile devices.

## Getting Started

You can run HishabHub locally:

1. Clone the repository:

   ```bash
   git clone https://github.com/YOUR-USERNAME/HishabHub.git
   ```

2. Open the project folder.

3. Open `index.html` in your browser.

No additional installation is required for the current demo.

## Project Status

<kbd>Demo / Work in Progress</kbd>

HishabHub is not yet a production-ready application. The current version focuses on demonstrating the interface and core business management workflows.

Data is currently handled on the frontend and does not persist after a page refresh.
